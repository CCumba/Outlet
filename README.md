# Outlet

Sitio web de una tienda virtual tipo outlet. Permite explorar productos organizados por categorías y subcategorías, buscar por nombre o característica, y contactar al vendedor por WhatsApp para coordinar la compra.

## Tecnologías

- HTML, CSS y JavaScript puro
- Bootstrap 5
- Google Sheets como base de datos de productos (vía CSV exportado)

## Funcionalidades

- Catálogo navegable por categoría y subcategoría
- Buscador de productos por nombre o característica
- Vista de "Todos los productos"
- Botón directo a WhatsApp con mensaje prellenado por producto
